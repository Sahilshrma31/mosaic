    Architecture

    One agent, any source

    A hand-written agent loop, no frameworks. Every data source runs as its own MCP server, so adding Calendar or Sheets means adding a server, not rewriting the agent.

    Swipe the diagram to see all of it
    Data flowWrite, only after your click
    Inside the loop

    It keeps going until it has the evidence

    Each round, Gemini either asks for more tools or answers. The code reads that signal, runs the tools and numbers what comes back. Nothing about the order is hardcoded.

    • It stops itself. A reply with no tool call is the final answer.
    • It can't run forever. After 6 rounds, the last one has tools switched off, so it answers with what it found.
    • It batches. Independent searches go in the same round; a search that needs an earlier result waits for the next.
    • It survives outages. If a model is overloaded or out of quota, the question restarts on the next one.
    Security

    It reads mail from strangers. They can't steer it.

    A mail can say anything, including "ignore your rules". So the hard limits live in code, not in the prompt, and hold even if the model is fooled.

    Flagged · treated as data

    Mail is data, not orders

    Text aimed at an AI gets flagged and can't prove anything. Every tool result is treated as untrusted.

    • search_emailsread
    • query_notionread
    • update_application_statushidden

    The model can't reach the write tool

    Only tools marked read-only are offered to Gemini. Asking for anything else is refused by code, not by the prompt.
