    Architecture

    One agent, any source

    A hand-written agent loop, no frameworks. Every data source runs as its own MCP server, so adding Calendar or Sheets means adding a server, not rewriting the agent.

    browserChat page
    POST /chatFastAPI
    GeminiAgent loop
    stdio · JSON-RPCMCP client
    MCP serverGmail
    → Gmail API
    MCP serverNotion
    → Notion API
    01

    Understand

    Loads chat history and long-term facts, then splits the question into sub-questions.

    02

    Search

    Calls the Gmail and Notion servers, batching independent searches into one round.

    03

    Reason

    Reads the evidence, spots stale or conflicting data, and searches again if needed.

    04

    Answer

    Writes a short answer with numbered sources and saves what's worth remembering.

    Built from scratch
